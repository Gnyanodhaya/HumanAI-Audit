# HumanAI-Audit
Deterministic linguistic audit suite featuring 7 analysis modules, authentic readability formulas (Flesch, FKGL, Gunning Fog, SMOG, ARI, Coleman-Liau), sentence cadence &amp; burstiness scoring, stock AI cliché detection, multi-format ingestion (.txt, .pdf, .docx), PDF summary report export, user audit history, and a responsive Streamlit-inspired dark.
